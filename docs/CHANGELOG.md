# Changelog

All notable changes to NoniKos are documented in this file.

This project follows a practical versioning approach to track improvements, new features, fixes, and technical updates.

## 1.0.0 — Initial Release

### Features
- Property and room management.
- Tenant management and occupancy tracking.
- Rental payment and arrears monitoring.
- Invoice generation and payment records.
- Financial reports and CSV/Excel exports.
- Owner and tenant dashboards.
- Role-based access control.
- Activity logs.
- Backup and restore functionality.
- Responsive interface with dark mode support.

### Technical
- Laravel-based application architecture.
- Database migrations and seeders.
- Automated application tests.
- Scheduled background tasks.
- Integration-ready architecture for external services.
